# SaQR Agency Bot

Telegram bot starter for SaQR Agency.

## تشغيل البوت

1. ثبّت Python 3.10 أو أحدث.
2. ثبّت المتطلبات:
   `pip install -r requirements.txt`
3. أنشئ متغير البيئة `BOT_TOKEN` وضع فيه التوكن الجديد.
4. شغّل:
   `python bot.py`

لا تضع التوكن الحقيقي داخل GitHub أو داخل ملفات المشروع.
